# RCCG Tabernacle of Praise — Repository Instructions

This repository supports the **Tabernacle of Praise** parish of the Redeemed Christian Church of God (RCCG), Istanbul, Türkiye.

Read and apply the repo-local skill at `.agents/skills/rccg-top-identity/SKILL.md` and its reference files when working on church branding, logos, typography, palettes, flyers, and media. Use the separate `logo-design` skill for logo methodology **only if it is available in this Codex environment**.

## Confirmed decisions
- Standalone parish wordmark: **Tabernacle of Praise**.
- Official name in descriptive church communications: **RCCG Tabernacle of Praise**.
- Create a modern, minimal **but expressive** distinctive local identity.
- Keep the official RCCG emblem as a **separate, unaltered, authorized** asset; pair it beside the parish identity for approved official lockups.
- Restrained color system with justifiable campaign-specific accents; authentic church photographs preferred, appropriately licensed conceptual images permitted.
- Present proposals for review. No final mark, exact HEX palette, or typography is approved yet.

## Don't
- Reuse rejected generic arch + stick-figure / doorway logo variants or closely imitate supplied inspiration logos.
- Force harp/string symbolism: it is an *idea to test* against strong non-musical designs.
- Invent official beliefs, vision, mission, events, service details, addresses, phone numbers, clergy, or contacts.
- Alter or redraw the official RCCG emblem.
- Create overly colorful, cluttered, generic church graphics; fake actual church photos; use unlicensed resources.
- Publish, schedule, or label anything final before explicit approval.

## Working style
Flag unanswered important creative decisions **before moving to a substantially new phase**. Keep concepts explicitly marked **DRAFT — NOT FOR PUBLICATION**. Maintain editable SVG/source files and include mobile-size tests. See the skill's `references/` for full brief, historical feedback, and media standards.
